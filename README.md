# Lux.Display (LuxStack)

Read-Only Display Blocks (19 kinds), Media Players with Clip/Play-Limit Rules, and Multi-Format File Preview for .NET, Blazor, and .NET MAUI:
- **`Lux.Display.Core`**: Headless `FilePreviewService` (MIME/extension detection across 10 renderer kinds, RFC 4180 CSV parser with delimiter detection, file size & extension formatting), and media playback rule models.
- **`Lux.Display`**: Blazor & MAUI Hybrid components (`BxDisplay`, `BxAudioPlayer`, `BxVideoPlayer`, `BxFilePreviewProvider`, `AddLuxDisplay()`).
