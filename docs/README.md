# Klyroo.Display documentation

The documentation follows the [Diátaxis](https://diataxis.fr/) structure: a tutorial for your first order page, how-to guides for code, secrets, media and previews, reference pages for APIs and platforms, and an explanation of how the pieces fit together.

## Tutorial

- [Getting started](getting-started.md): install, register, add the stylesheets and build an order page with a code block, a masked key, a file list and a file preview.

## How-to guides

- [Guides](guides.md): code samples, line numbers and emphasized lines, headless highlighting, secrets, attachment lists, file galleries, CSV and Markdown preview, play limits, restyling, headless helpers and testing.

## Reference

- [API reference](api-reference.md): every public type and member, generated from the XML documentation.
- [Platforms](platforms.md): render modes, .NET MAUI (Blazor Hybrid and native views), NativeAOT and trimming, and known limitations.
- [FAQ](faq.md): troubleshooting by symptom, and frequent questions.
- [Changelog](../CHANGELOG.md): what each release adds.

## Explanation

- [Concepts](concepts.md): the two packages, how the code, secret and file list blocks, `FilePreviewService` and the media players work, and the design decisions behind them.
